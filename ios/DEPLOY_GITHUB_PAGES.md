# Fast deployment to GitHub Pages

1. Create a new GitHub repository, e.g. `ios-asset-forge`.
2. Upload the files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)` and save.
6. Open the generated `https://USERNAME.github.io/ios-asset-forge/` URL.

No GitHub Actions workflow is required because this is a static site.
