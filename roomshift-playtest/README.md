# ROOMSHIFT playtest build

Neon look by default (Neon / Soft switch on Home and Pause), visor robot, locked physics core v1.0.0, audio v0.3.

## Put it on GitHub Pages
1. Create a new repository on github.com (for example `roomshift-playtest`).
2. Upload everything in this folder, keeping the `sounds` and `music` folders, with `index.html` at the top level.
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
4. After a minute the game is at `https://<your-username>.github.io/roomshift-playtest/`.

## For testers
- Open the link in Safari or Chrome on the phone, turn the silent switch off, tap Play.
- About 14 MB loads on first open; the music fades in a few seconds after the first run starts.
- Best score and rank are saved only in that phone's browser.

This must be served from a web address; opening index.html directly from Files, WhatsApp or email will not load the sound.
